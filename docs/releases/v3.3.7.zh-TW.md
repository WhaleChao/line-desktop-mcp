# LINE Desktop MCP 3.3.7 更新說明

修正多行長文使輸入框變高、既有訊息上移時，聊天室核對可能誤拒絕的情況。只允許原日期與最後兩則訊息一同上下移動：尺寸、相對位置、完整可見範圍及所有原始畫面指紋必須一致；視窗、帳號／聊天室識別、限定訊息頁、token 期限與完整草稿核對仍保留。內容改變或被裁切仍拒絕送出。

送出流程保留經限制的內層錯誤碼 `previousCode`，方便區分回讀失敗與聊天室／畫面變動，不輸出私人原文或底層診斷。不確定的草稿不會自動重播，既有傳訊授權、防重送與本機覆核不變。

本批以合成長文與拒絕案例驗證，沒有再操作 LINE 或傳送測試訊息。其他業務任務回報既有訊息已完成本機覆核；這個版本不宣稱新的實際傳送或獨立伺服器送達／已讀證明。
