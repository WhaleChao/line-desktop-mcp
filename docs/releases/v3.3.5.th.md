# v3.3.5 — แก้ OCR หมวดหมู่และชื่อในผลค้นหาแบบผสม

2026-09-29 (Asia/Taipei)

การค้นหาที่มีแชตหนึ่งรายการกับผลข้อความแยกกันยังอาจปฏิเสธแชตที่ไม่ซ้ำ เพราะภาพตัดชื่อ 30px มีพื้นที่ว่างด้านล่างไม่พอให้อ่านชื่อเต็ม ส่วน OCR ที่ชิดขอบของหัวข้อหมวดหมู่แยกต่างหากอาจอ่านตัวอักษรหรือจำนวนไม่ครบ v3.3.5 ตัดแต่ละหมวดหมู่จากแถว UIA ของตัวเอง ใช้ภาพตัดชื่อ 35px และเพิ่มขอบขาว 16px ให้ OCR ได้เมื่อจำเป็น พิกัดถูกแปลงกลับภาพต้นฉบับ และปฏิเสธหลักฐานที่ออกนอกขอบ

ยังต้องตรวจแท็บที่เลือก คำค้นตรงกัน จำนวนแชตหนึ่งรายการ ชื่อเต็ม ชื่อเต็มที่ตรงกันของหน้าต่างแยก และตัวตนบัญชี/แชตในเครื่อง การป้องกันการส่งไม่เปลี่ยน การแก้นี้ปรับหลักฐานการนำทางเท่านั้น ไม่เพิ่มการยืนยันตัวตนด้วยสีหรืออนุญาตให้ส่งข้อความ

การทดสอบที่เกี่ยวข้อง 61 รายการผ่านโดยไม่ล้มเหลว แบ่งเป็นการทดสอบ scoped OCR การค้นหาแบบตรงชื่อ การส่งแบบปรับปรุง และเป้าหมายผู้รับ 54 รายการ รวมกับการทดสอบ native OCR อีก 7 รายการ การค้นหาจริงแบบเริ่มเย็นผ่านหน้าต่างหลัก 5 ครั้งในแชตส่วนตัวที่ได้รับอนุญาต 3 ห้องถึง READY ทุกครั้ง โดยชื่อเต็มของหน้าต่างแยกตรงกัน ตัวตนในเครื่องตรงกัน และช่องพิมพ์ว่าง ไม่มีการพิมพ์หรือส่งข้อความ การทบทวนอิสระแบบจำกัดไม่พบปัญหาที่ขวางงาน

ไม่เปลี่ยน dependencies, schema สาธารณะ, การจัดการร่าง หรือบันทึกป้องกันส่งซ้ำ เผยแพร่ผ่านแท็กซอร์ส GitHub พร้อมไฟล์ `.tgz` และ `SHA256SUMS.txt` โดยไม่มี npm registry หรือ MCPB
