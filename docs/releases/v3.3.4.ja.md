# v3.3.4 — 個人チャット単一結果のカテゴリ OCR 修正

2026-09-29 (Asia/Taipei)

検索結果全体の OCR が、強調表示された単一の個人チャット名の横にある薄いチャットのカテゴリ／件数を見落とし、一意の結果を拒否する場合がありました。v3.3.4 では同じ観測済みスクリーンショットからカテゴリを別に切り出して読み取ります。まず既存の単一結果の画面移動確認を試し、通常の Friends 複数結果とチャット／メッセージの混在検索は従来の経路を使います。

選択済み Friends タブ、完全一致の検索語、チャットの件数と行が各 1 件であること、個別ウィンドウの完全なタイトル、およびローカルのアカウント／チャット照合は引き続き必要です。緑色のタイトルを色や文字で新たに身元確認する機能は追加していません。不明確な証拠では拒否します。

範囲を絞った OCR テスト 8 件と関連する検索・送信・身元テスト 45 件、計 53 件が合格しました。許可された 1 件の実機準備では完全一致の個別個人チャットを開き、ローカル参照と空の入力欄を確認しました。入力・送信は行っていません。Node／Python の全テストは再実行しておらず、新たな広範囲のセキュリティスキャンも主張しません。

依存関係、公開ツール schema、下書き処理、再送防止記録は変更しません。GitHub のソースタグと添付 `.tgz`・`SHA256SUMS.txt` で配布し、npm registry や MCPB では公開しません。
