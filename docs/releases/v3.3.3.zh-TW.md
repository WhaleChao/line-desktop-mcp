# v3.3.3 — 最近聊天室群組清單修正

2026-09-29（Asia/Taipei）

LINE 的 `_chat` 是通用聊天室索引，群組也可能有 `_midType=2` 的資料列。最近聊天室清單先前把每筆 `_chat` 都當成個人聊天室身分，導致同時出現在 `_groupChat` 與 `_chat` 的有效群組被誤判衝突而排除。現在只有 `_midType=0` 才視為個人聊天室，與既有指定名稱的解析方式一致；真正跨類型或名稱衝突仍會排除。

五項聚焦 Python 最近聊天室測試、三項 Node 契約測試通過；修正前有兩項回歸案例失敗。對單一已授權群組的唯讀實測顯示，舊版排除該群組，修正後列出同一群組參照。這次只讀中繼資料，未讀訊息本文，也沒有 GUI 操作或發送。獨立的限縮審查未發現阻擋發布的安全問題；本次不宣稱已重跑完整 Node 或 Python 測試。

傳送、視窗、搜尋防護、工具 schema、依賴與防重送紀錄不變。透過 GitHub 原始碼 tag、附檔 `.tgz` 與 `SHA256SUMS.txt` 發布；沒有 npm registry 或 MCPB 版本。
