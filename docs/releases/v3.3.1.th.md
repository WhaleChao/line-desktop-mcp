# v3.3.1 — แก้ไขการค้นหากลุ่ม

แก้การปฏิเสธ `LINE_SEARCH_NOT_UNIQUE` ที่เกิดจากหัวข้อผลค้นหาแบบแชตและชื่อกลุ่มยาวที่ถูกตัด

- ใช้ผลลัพธ์เชิงโครงสร้างหนึ่งรายการเพื่อเปิดหน้าต่างเท่านั้น ก่อนพิมพ์ยังต้องตรวจชื่อเต็มของหน้าต่างแยก ตัวระบุแชต บัญชีตนเอง ประเภทกลุ่ม และชื่อที่ไม่ซ้ำ พร้อมตรวจอีกครั้งก่อนส่ง
- การตรวจตัวตนส่งคืน `ownSenderRef` ที่ตรวจแล้วเมื่อระบุบัญชีที่คาดหวัง บัญชีผิดยังถูกปฏิเสธ
- ไม่เปลี่ยนแชตส่วนตัว schema เครื่องมือ dependencies หรือการป้องกันส่งซ้ำ

Node ผ่าน 353 รายการ; Python ทดสอบ 136 ผ่าน 128 ข้ามตามสภาพแวดล้อม 8 รายการ การเตรียมกลุ่มบนเครื่องจริงใช้ 10.266 วินาที ตรวจการค้นหา เปิดหน้าต่าง ตัวตน และช่องพิมพ์ว่าง โดยไม่ได้พิมพ์หรือส่งข้อความ โค้ดทำงานตรงกับ `3.3.1-local.1` ที่ติดตั้งแล้ว การตรวจความปลอดภัยเฉพาะส่วนเปลี่ยนแปลงไม่พบช่องโหว่ที่ยืนยันได้ ไม่ใช่การรับรองทั้ง repository

ชื่อหน้าต่างและฐานข้อมูลท้องถิ่นเป็นหลักฐานแยกกัน ข้อมูล accessibility ของ Qt อาจไม่ครบ หากมีหลายผลลัพธ์ยังใช้การตรวจชื่อเต็มเดิม และหยุดเมื่อยืนยันตัวตนไม่ได้ แพ็กเกจสาธารณะไม่รวมแชตส่วนตัว ภาพหน้าจอ หรือบันทึกวินิจฉัย
