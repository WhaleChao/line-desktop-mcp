# v3.3.0 — 宛先の結び付けと転送の確認

2026-09-24 公開。Windows 拡張は **33 個のツール**を表示し、旧エイリアス 5 個は一覧に出さずに呼び出せます。標準の 5 ツールと読み取り専用 CLI は互換です。配布は GitHub のソースタグと `.tgz` で行い、npm には公開しません。

## 変更点

- `list_line_recent_chats` は直近 14 日または 30 日（台北の日付）に活動した個人／グループチャットの名前と不透明な識別参照を列挙します。メッセージ本文やメディアは読みません。
- `check_line_send_target` はメッセージや GUI を使わずに宛先を確認します。`expectedChatRef` と `expectedOwnSenderRef` の組で対象チャットと現在のアカウントを固定し、不一致ならメッセージの読み取りや入力より前に拒否します。
- 既存の個人チャットが一意でも、未開封の同名連絡先がある場合に対応しました。正確なタイトルのウィンドウがすでに開いており、直近の異なる 2 件のテキスト、表示日付、分単位の時刻、方向、空の入力欄を独立して照合できる場合に限ります。`prepare_line_send_target` は入力・送信せず準備状態を返し、送信時に再検証します。ほかの名前衝突は引き続き拒否し、元から一意の宛先は従来どおり自動で開けます。
- 原メッセージの転送に `prepare_line_forward`、`confirm_line_forward`、`verify_line_forward`、`cancel_line_forward` を追加しました。原メッセージ、アカウント、単一の宛先を確認済み操作に結び付けます。Share の結果が不確かな場合に自動再試行しないよう、送信意図を永続化します。キャンセルできるのは送信前だけで、送信取消ではありません。
- 正確な検索では、読み取れる一致候補が一意なら 2 番目の結果も選択できます。台北の深夜をまたぐ記録確認は範囲を限定し、新しいページが途中で切れる場合は前のページとの重複を要求します。

## 検証と制限

Node テスト **349 件が成功**。Python は **135 件実行、127 件成功、8 件スキップ**（記録した環境）。新規 stdio 起動でバージョンと 33 ツールを確認しました。正式版の実行コードは、実機検証済みの `3.3.0-local.4` 候補版と同じです。

Windows LINE 26.4.2.3957 では、宛先を固定した個人チャットの準備、誤ったチャット／アカウントの拒否、呼び出し元アプリ経由で承認済みの通常テキストを 1 件送信する操作を実機で確認しました。新しい自分のローカル記録は承認した全文と一致しました。転送候補版も合成添付ファイルで試し、その転送メッセージは後でガイド付き LINE UI から取り消しました。特殊な個人チャットの準備に約 5.6 秒かかった観測例がありますが、一般的な速度保証ではありません。

`RECORDED_LOCAL` や一致するローカル記録は、相手への配信・既読を**証明しません**。添付ファイルの名前とサイズの一致もバイト単位の同一性を証明しません。特殊な個人チャット経路には、同じ日に表示された異なる 2 件のテキストが必要です。欠落、切り詰め、テキスト以外、曖昧な文脈では拒否する場合があります。記載のないリッチ機能や UI 言語は、このリリースで新たに認証されていません。私的なチャット内容、識別子、画面、操作記録は配布物に含めません。
