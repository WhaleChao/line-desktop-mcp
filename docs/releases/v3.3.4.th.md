# v3.3.4 — แก้ OCR หมวดหมู่สำหรับผลแชตส่วนตัวหนึ่งรายการ

2026-09-29 (Asia/Taipei)

OCR ของผลค้นหาทั้งหน้าอาจอ่านหมวดหมู่/จำนวนแชตสีจางข้างชื่อแชตหนึ่งรายการที่ถูกเน้นไม่พบ ทำให้ปฏิเสธผลที่ไม่ซ้ำ v3.3.4 อ่านหมวดหมู่จากภาพตัดแยกของภาพหน้าจอที่สังเกตไว้ภาพเดียวกัน โดยลองการตรวจนำทางผลแชตส่วนตัวหนึ่งรายการแบบเดิมก่อน ส่วนผล Friends ปกติและผลค้นหาที่มีแชตปนข้อความยังใช้เส้นทางเดิม

ยังต้องตรวจแท็บ Friends ที่เลือกอยู่ คำค้นตรงกัน จำนวนและแถวแชตอย่างละหนึ่งรายการ ชื่อเต็มของหน้าต่างแยก และการผูกบัญชี/แชตในเครื่อง ชื่อสีเขียวไม่ได้กลายเป็นตัวตรวจตัวตนจากสีหรือข้อความแบบใหม่ หลักฐานที่ไม่ชัดเจนยังถูกปฏิเสธ

การทดสอบ OCR เฉพาะจุด 8 รายการและการทดสอบการค้นหา การส่ง และตัวตนที่เกี่ยวข้องอีก 45 รายการ ผ่านรวม 53 รายการ การเตรียมแชตจริงหนึ่งเป้าหมายที่ได้รับอนุญาตเปิดหน้าต่างแชตส่วนตัวที่ชื่อเต็มตรงกัน ตรวจค่าอ้างอิงในเครื่องและช่องพิมพ์ว่าง โดยไม่ได้พิมพ์หรือส่งข้อความ ไม่ได้รันชุดทดสอบ Node/Python ทั้งหมดใหม่ และไม่อ้างว่ามีการสแกนความปลอดภัยวงกว้างครั้งใหม่

ไม่เปลี่ยน dependencies, schema เครื่องมือสาธารณะ, การจัดการร่าง หรือบันทึกป้องกันส่งซ้ำ เผยแพร่ผ่านแท็กซอร์ส GitHub พร้อมไฟล์ `.tgz` และ `SHA256SUMS.txt` โดยไม่มี npm registry หรือ MCPB
