# v3.3.0 — 收件人綁定與轉發核對

發布日期：2026-09-24。Windows 擴充目前列出 **33 個工具**，另保留 5 個可呼叫但不列出的舊別名。五個預設工具與唯讀 CLI 保持相容；透過 GitHub tag 與 `.tgz` 發布，不發布至 npm。

## 這次更新

- **最近聊天室清單**：`list_line_recent_chats` 列出最近 14／30 個台北日曆日活躍的個人與群組名稱、識別參照及活動時間，不讀取訊息文字或媒體。
- **先核對收件人**：`check_line_send_target` 不讀訊息、不操作介面。以 `expectedChatRef` 和 `expectedOwnSenderRef` 綁定選定聊天室與目前帳號；不符時在讀取訊息或輸入前拒絕。
- **修正同名好友擋住既有對話**：既有個人聊天室唯一，但其他未開啟對話的好友同名時，可透過精確標題的已開啟視窗，獨立核對最近兩則不同文字、日期、分鐘、方向與空白輸入框。`prepare_line_send_target` 只回報準備狀態，不打字、不傳送；真正送出時重新核對。其他聊天室或顯示名稱衝突仍拒絕；原本名稱唯一的對象保留自動開啟流程。
- **原訊息轉發**：新增 prepare／confirm／verify／cancel 四個轉發工具，將原訊息、帳號及單一收件人綁定於同一筆已審操作。實際按下分享前先保存送出意圖，結果不確定時只核對、不自動重送。cancel 僅取消尚未送出的準備，不是收回。
- **搜尋與回執修正**：精確名稱出現在第二筆搜尋結果也可定位；跨台北午夜的回執仍維持限定日期範圍，分頁截斷時必須與送出前紀錄重疊。

## 已驗證與限制

Node **349 項通過**；Python **135 項執行、127 項通過、8 項依環境略過**。全新 stdio 連線確認版本與 33 個工具。正式版沿用已實測 `3.3.0-local.4` 的執行程式碼。

Windows LINE 26.4.2.3957 實機驗證了綁定直聊準備、錯誤聊天室／帳號拒絕，以及呼叫端應用程式送出一次已批准的普通文字；本機資料庫找到全新的本人訊息，完整原文一致。轉發候選版另以合成附件實測，並透過 LINE 介面收回該次新轉發訊息。特殊直聊準備單次約 **5.6 秒**，不代表所有電腦或操作都能達到此速度。

本機紀錄與 `RECORDED_LOCAL` **不代表對方收到或已讀**；附件名稱／大小相符也不等於內容位元組一致。特殊直聊路徑目前需要同一天最近兩則不同且可見的文字；非文字、裁切、缺失或不明確的內容可能拒絕。未另行實測的豐富功能與其他介面語言，不因此視為通過。公開版本不包含私人聊天、識別碼、畫面或操作回執。
