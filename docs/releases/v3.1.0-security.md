# v3.1.0 release verification

2026-09-22 (Asia/Taipei)

The source review covered all seven changed runtime/config files between
v3.0.1 and the initial v3.1.0 candidate: package metadata and lockfile, CLI
entry point, command parser, result formatting, shared export helper, and MCP
export integration. Supporting local-reader and formatting code was traced as
needed. A separate reviewer mapped representative repository trust boundaries.
This was a diff review, not an exhaustive audit of unchanged code.

One low-severity issue was found and fixed before release: stored chat text
and sender labels could contain terminal controls that the new human-readable
CLI printed unchanged. A synthetic result accepted by the actual reader
validator reproduced raw ESC and CR at stdout. The final output sink renders
terminal and directional controls visibly. JSON preserves original strings.
The targeted regression failed before the fix and passed afterward.

- Node: 249 passed, zero failures.
- Python: 124 passed, one Windows file-symlink privilege skip (125 total).
- Production dependency audit: zero known npm vulnerabilities at check time.
- Package review: no dependency trees, caches, exports, local run records, or
  private machine paths in the release inventory; bounded token/private-key
  pattern checks found no matches. This is not a guarantee that every possible
  secret format can be detected.

Exact chat/date/cursor validation, metadata-only CLI reads, safe diagnostic
envelopes, CSV formula-prefix handling, exclusive export creation, and export
readback checks were reviewed. The MCP GUI/send controls were not widened.
The extension capability version and package/CLI versions are 3.1.0.

No live LINE chat, GUI action, or send was used for this release verification.
The control-byte reproduction used synthetic stored content, not a real LINE
transport. Exports rely on a private, stable destination directory: path checks
are not a defense against an attacker replacing parent directories concurrently,
and the helper does not install private ACLs or prevent syncing/backups.
