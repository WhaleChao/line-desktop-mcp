# v3.3.4 — 單筆個人搜尋分類 OCR 修正

2026-09-29（Asia/Taipei）

整張搜尋結果的 OCR 可能漏掉醒目標題旁較淡的聊天室分類／筆數，讓原本唯一的個人聊天室結果被拒絕。本版從同一張已觀察的截圖另外裁切分類區辨識，先走既有的「單筆個人聊天室」導覽核對；一般多筆好友結果與聊天室／訊息混合結果沿用原路徑。

仍須核對已選取「好友」、精確查詢、聊天室計數與結果列各一筆、獨立視窗完整標題及本機帳號／聊天室身分。畫面上綠色標題並沒有新增顏色或文字身分驗證；證據不明仍會拒絕。

8 項範圍 OCR 測試加上 45 項相關搜尋、傳送與身分測試，共 53 項通過。單一已授權對象的實機準備開啟完整標題吻合的獨立個人聊天室，核對本機參照及空白輸入框；沒有輸入或發送訊息。本次未重跑完整 Node／Python 測試，也不宣稱進行新的全面安全掃描。

依賴、公開工具 schema、草稿處理及防重送紀錄不變。透過 GitHub 原始碼 tag、附檔 `.tgz` 與 `SHA256SUMS.txt` 發布；沒有 npm registry 或 MCPB。
