# v3.1.0 — CLI lokal hanya-baca

2026-09-22 · [GitHub Release](https://github.com/bensonmaxai/line-desktop-mcp/releases/tag/v3.1.0)

Menambahkan `line-cli` untuk daftar kemampuan, status lokal, pembacaan chat tertentu menurut tanggal, dan ekspor JSON/TXT/CSV. Setiap pemanggilan mengembalikan satu halaman dengan rentang maksimal 31 hari. CLI tidak mengoperasikan GUI atau mengirim pesan.

Tools MCP dan batas keamanan v3 tetap berlaku. Ekspor tidak menimpa file yang ada dan memverifikasi isi serta hash setelah penulisan; TXT/CSV menyebutkan kolom yang tidak disertakan.

Pemeriksaan keamanan sebelum rilis memperbaiki injeksi karakter kontrol terminal. Output yang dibaca manusia menampilkan escape yang terlihat; JSON mempertahankan teks asli.

```powershell
node src/cli.js --version
node src/cli.js capabilities --json
node src/cli.js messages read --chat "Exact chat name" --from 2026-09-01 --to 2026-09-07 --limit 100 --json
```

Verifikasi memakai data sintetis dan uji regresi sistem file. Rilis ini tidak mengklaim pengujian pembacaan chat LINE nyata, tindakan GUI, atau pengiriman pesan.
