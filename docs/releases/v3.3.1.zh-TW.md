# v3.3.1 — 群組搜尋修復

修正群組搜尋結果顯示「聊天」、長名稱被截斷時，錯誤回報 `LINE_SEARCH_NOT_UNIQUE` 的問題。

- 群組搜尋只有一個結構候選時，先開啟核對；搜尋列本身不代表身分已驗證。
- 輸入前仍須獨立聊天室完整標題吻合，並重新核對聊天室、本人帳號、群組類型及名稱唯一性；送出前再次核對。
- 修正身分查詢已核對預期帳號，卻漏回傳 `ownSenderRef` 的問題。錯誤帳號仍拒絕。
- 個人聊天室路徑、工具 schema、依賴及防重送紀錄不變。

驗證：Node 353 項通過；Python 136 項執行、128 項通過、8 項依環境略過。實機約 10.266 秒完成群組搜尋、開啟、身分及空白輸入框核對；這次群組驗收沒有輸入或發送訊息。執行程式碼與已安裝的 `3.3.1-local.1` 相同。針對本次差異的安全檢查未發現已確認漏洞；不是全儲存庫安全保證。

UI 標題與本機資料庫是獨立證據，並非直接的視窗到資料庫識別映射。Qt 可提供部分可及性資料；多列或未通過結構核對時保留既有完整名稱核對流程，不能證明對象時停止。公開套件不包含私人聊天、截圖或診斷回執。
