# v3.3.1 — Perbaikan pencarian grup

Memperbaiki penolakan `LINE_SEARCH_NOT_UNIQUE` saat LINE menampilkan kategori chat dan memotong nama grup yang panjang.

- Satu hasil struktural hanya dipakai untuk navigasi. Sebelum mengetik, judul lengkap jendela terpisah serta chat, akun sendiri, jenis grup dan keunikan nama diperiksa kembali. Pemeriksaan sebelum kirim tetap berlaku.
- Pencarian identitas mengembalikan `ownSenderRef` yang telah diperiksa bila akun yang diharapkan diberikan. Akun salah tetap ditolak.
- Alur chat langsung, schema alat, dependencies dan jurnal pencegah pengiriman ulang tidak berubah.

353 tes Node lulus. Python menjalankan 136: 128 lulus, delapan dilewati karena lingkungan. Persiapan grup langsung selesai dalam 10.266 detik, mencakup pencarian, pembukaan, identitas dan kolom pesan kosong; tidak ada pesan diketik atau dikirim. Kode runtime sama dengan `3.3.1-local.1` terpasang. Pemeriksaan keamanan perubahan ini tidak menemukan kerentanan terkonfirmasi; bukan jaminan keamanan seluruh repository.

Judul jendela dan data lokal merupakan bukti terpisah, bukan pengenal langsung jendela ke database. Accessibility Qt bisa tidak lengkap. Banyak hasil tetap memakai pemeriksaan nama lengkap sebelumnya; identitas yang belum pasti ditolak. Paket publik tidak memuat chat pribadi, tangkapan layar atau catatan diagnostik.
