# v3.3.3 — แก้รายการกลุ่มแชตล่าสุด

2026-09-29 (Asia/Taipei)

ตาราง `_chat` ของ LINE เป็นดัชนีแชตทั่วไปและอาจมีแถวของกลุ่ม (`_midType=2`) ก่อนหน้านี้ตัวเลือกแชตล่าสุดมองทุกแถวใน `_chat` เป็นตัวตนของแชตส่วนตัว จึงตัดกลุ่มที่ถูกต้องซึ่งอยู่ทั้งใน `_groupChat` และ `_chat` ออกเพราะเข้าใจผิดว่าเป็นข้อมูลขัดแย้ง ตอนนี้ใช้เฉพาะ `_midType=0` เป็นตัวตนแชตส่วนตัว ตามตัวแก้ชื่อแชตเดิม ส่วนความขัดแย้งของประเภทหรือชื่อจริงยังถูกตัดออก

การทดสอบ Python แบบเฉพาะจุดสำหรับแชตล่าสุด 5 รายการ และการทดสอบสัญญา Node 3 รายการผ่าน ก่อนแก้ไขกรณีถดถอย 2 รายการล้มเหลว การอ่านเฉพาะกลุ่มจริงหนึ่งกลุ่มที่ได้รับอนุญาตพบว่าเส้นทางเดิมตัดกลุ่มนี้ออก ส่วนเส้นทางที่แก้แล้วคืนค่าอ้างอิงกลุ่มเดิม การตรวจนี้อ่านเฉพาะ metadata ไม่อ่านข้อความ ไม่ใช้ GUI และไม่ส่งข้อความ การทบทวนอิสระแบบจำกัดไม่พบปัญหาความปลอดภัยที่ขวางการเผยแพร่ ไม่มีการอ้างว่ารันชุดทดสอบ Node หรือ Python ทั้งหมดใหม่

ไม่เปลี่ยนการส่ง การป้องกันหน้าต่างหรือการค้นหา schema เครื่องมือ dependencies หรือบันทึกการส่ง เผยแพร่ผ่านแท็กซอร์ส GitHub ไฟล์แนบ `.tgz` และ `SHA256SUMS.txt` โดยไม่มี npm registry หรือ MCPB
