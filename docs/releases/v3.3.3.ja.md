# v3.3.3 — 最近のグループ一覧の修正

2026-09-29 (Asia/Taipei)

LINE の `_chat` は共通のチャット索引であり、グループ行（`_midType=2`）も含まれます。以前の最近のチャット一覧は、`_chat` の各行を個人チャットの身元と扱い、`_groupChat` と `_chat` の両方にある正常なグループを誤った競合として除外していました。今回、既存の名前指定リゾルバーと同じく `_midType=0` だけを個人チャットの身元として扱います。実際の種別・名前の競合は引き続き除外します。

最近のチャットに関する Python の集中テスト 5 件と Node の契約テスト 3 件が合格しました。修正前は回帰ケース 2 件が失敗していました。許可された 1 つの実グループのみを対象にした読み取りでは、旧経路は除外し、修正後は同じグループ参照を返しました。この確認はメタデータのみで、本文、GUI 操作、送信はありません。限定的な独立レビューでは公開を妨げるセキュリティ問題は見つかりませんでした。今回は Node／Python の全テストを再実行したとは主張しません。

送信、ウィンドウ・検索ガード、ツール schema、依存関係、記録には変更がありません。GitHub のソースタグ、添付 `.tgz`、`SHA256SUMS.txt` で配布し、npm registry や MCPB では公開しません。
