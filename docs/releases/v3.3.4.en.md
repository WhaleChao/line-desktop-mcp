# v3.3.4 — Single direct-search category OCR

2026-09-29 (Asia/Taipei)

Whole-results OCR could miss the faint chat category/count beside a highlighted single direct-chat title and refuse an otherwise unique result. v3.3.4 reads that category in a separate crop from the same observed screenshot. It first tries the existing navigation-only single-direct validation; ordinary Friends results and mixed chat/message searches keep their existing paths.

The selected Friends tab, exact query, one chat count and row, exact detached window title, and local account/chat binding are still required. The visible green title does not become a new color or text identity verifier. Ambiguous evidence still refuses.

Eight scoped-OCR tests and 45 related search, send and identity tests passed (53 total). An authorized live preparation opened the exact detached direct chat, confirmed matching local references and an empty composer. No message was entered or sent. The full Node and Python suites were not rerun; no new broad security scan is claimed.

Dependencies, public tool schemas, draft handling and send journals are unchanged. Distribution is a GitHub source tag with attached `.tgz` and `SHA256SUMS.txt`, without npm-registry or MCPB publication.
