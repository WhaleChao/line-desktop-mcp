# v3.3.5 — 混在検索のカテゴリとタイトル OCR 修正

2026-09-29 (Asia/Taipei)

チャット 1 件と別区画のメッセージ一致が並ぶ検索では、30px のタイトル切り出しでは下側の余白が足りず完全な名前を読み取れず、別に区画見出しの端に接した OCR が文字や件数を見落として、一意のチャットを拒否する場合がありました。v3.3.5 は各カテゴリをそれぞれの UIA 行から切り出し、タイトル範囲を 35px に広げ、必要に応じて OCR に 16px の白い余白を付けます。座標は元画像へ戻し、範囲外の証拠は拒否します。

選択済みタブ、完全一致の検索語、チャット 1 件の件数、完全な名前、個別ウィンドウの完全一致タイトル、ローカルのアカウント／チャット照合は引き続き必要です。送信ガードは変更しません。これは画面移動の証拠を修正するもので、色による身元確認や送信許可を追加しません。

関連テスト 61 件が失敗 0 件で合格しました。内訳は範囲 OCR・完全一致検索・最適化送信・送信先のテスト 54 件とネイティブ OCR テスト 7 件です。許可された個人チャット 3 件について、メインウィンドウからの実機コールド検索 5 回がすべて READY に達し、個別ウィンドウの完全一致タイトル、ローカルの身元一致、空の入力欄を確認しました。入力・送信はありません。独立した限定レビューに阻害要因はありませんでした。

依存関係、公開 schema、下書き処理、再送防止記録は変更しません。GitHub のソースタグと添付 `.tgz`・`SHA256SUMS.txt` で配布し、npm registry や MCPB では公開しません。
