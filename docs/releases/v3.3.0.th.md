# v3.3.0 — ผูกผู้รับและตรวจสอบการส่งต่อ

เผยแพร่ 2026-09-24 ส่วนขยาย Windows แสดง **33 tools** และยังเรียก alias เดิม 5 ตัวที่ซ่อนจากรายการได้ เครื่องมือค่าเริ่มต้น 5 ตัวและ CLI แบบอ่านอย่างเดียวยังคงเข้ากันได้ เผยแพร่ผ่าน GitHub source tag และ `.tgz` ไม่เผยแพร่บน npm

## การเปลี่ยนแปลง

- `list_line_recent_chats` แสดงชื่อแชตส่วนตัว/กลุ่มและตัวอ้างอิงตัวตนแบบ opaque ที่มีกิจกรรมใน 14 หรือ 30 วันปฏิทินตามเวลาไทเป โดยไม่อ่านข้อความหรือสื่อ
- `check_line_send_target` ตรวจตัวตนผู้รับโดยไม่อ่านข้อความหรือใช้ GUI คู่ `expectedChatRef` และ `expectedOwnSenderRef` ผูกแชตที่เลือกกับบัญชีปัจจุบัน หากไม่ตรงกันจะปฏิเสธก่อนอ่านข้อความหรือป้อนข้อมูล
- เมื่อแชตส่วนตัวเดิมมีเพียงหนึ่งรายการ แต่มีรายชื่อที่ยังไม่เปิดและชื่อซ้ำกัน สามารถใช้หน้าต่างที่เปิดอยู่และมีชื่อเรื่องตรงกันได้ โดยต้องตรวจข้อความล่าสุดสองรายการที่ต่างกัน วันที่ที่มองเห็น เวลาเป็นนาที ทิศทางข้อความ และช่องพิมพ์ที่ว่างอย่างอิสระ `prepare_line_send_target` รายงานความพร้อมโดยไม่พิมพ์หรือส่ง และตรวจซ้ำเมื่อส่งจริง กรณีชื่อ/แชตซ้ำแบบอื่นยังถูกปฏิเสธ ส่วนผู้รับที่ชื่อไม่ซ้ำยังเปิดอัตโนมัติได้ตามเดิม
- เพิ่ม `prepare_line_forward`, `confirm_line_forward`, `verify_line_forward` และ `cancel_line_forward` สำหรับส่งต่อข้อความต้นฉบับ โดยผูกต้นทาง บัญชี และผู้รับหนึ่งรายกับการดำเนินการที่ตรวจแล้ว บันทึกเจตนาส่งแบบถาวรก่อนกด Share เพื่อไม่ส่งซ้ำอัตโนมัติเมื่อผลไม่แน่นอน การยกเลิกทำได้เฉพาะก่อนส่ง และไม่ใช่การเรียกคืนข้อความ
- การค้นหาแบบตรงกันสามารถเลือกผลลัพธ์ลำดับที่สองที่อ่านได้ หากมีเพียงรายการเดียวที่ตรงกัน การตรวจบันทึกข้ามเที่ยงคืนเวลาไทเปยังจำกัดช่วง และเมื่อหน้าใหม่ถูกตัดต้องซ้อนทับกับหน้าก่อนหน้า

## การตรวจสอบและข้อจำกัด

Node tests **ผ่าน 349 รายการ**; Python **รัน 135 รายการ ผ่าน 127 และข้าม 8** ในสภาพแวดล้อมที่บันทึกไว้ การเริ่ม stdio ใหม่รายงานเวอร์ชันและ 33 tools ถูกต้อง โค้ด runtime ของรุ่นเผยแพร่ตรงกับ `3.3.0-local.4` ที่ทดสอบกับ LINE จริง

การตรวจบน Windows LINE 26.4.2.3957 ครอบคลุมการเตรียมแชตส่วนตัวแบบผูกตัวตน การปฏิเสธแชต/บัญชีผิด และการส่งข้อความธรรมดาที่อนุมัติแล้วหนึ่งครั้งผ่านแอปที่เรียกใช้ พบบันทึกใหม่ของตนในเครื่องที่ตรงกับข้อความที่อนุมัติครบถ้วน รุ่นผู้สมัครของการส่งต่อทดสอบด้วยไฟล์แนบสังเคราะห์ และภายหลังเรียกคืนข้อความที่ส่งต่อผ่าน LINE UI แบบมีผู้กำกับ การเตรียมแชตส่วนตัวกรณีพิเศษใช้ประมาณ 5.6 วินาทีในการสังเกตหนึ่งครั้ง ไม่ใช่การรับประกันความเร็วทั่วไป

`RECORDED_LOCAL` และบันทึกในเครื่องที่ตรงกัน **ไม่พิสูจน์ว่าผู้รับได้รับหรืออ่านแล้ว** ชื่อ/ขนาดไฟล์แนบที่ตรงกันก็ไม่พิสูจน์ว่าไบต์ตรงกัน กรณีแชตส่วนตัวพิเศษต้องมีข้อความที่ต่างกันสองรายการซึ่งมองเห็นได้ในวันเดียวกัน หากข้อความหาย ถูกตัด ไม่ใช่ข้อความ หรือบริบทกำกวม ระบบอาจปฏิเสธ ฟีเจอร์เพิ่มเติมและภาษา UI นอกเหนือจากที่ตรวจจริงไม่ได้รับการรับรองใหม่ในรุ่นนี้ ไม่แจกจ่ายเนื้อหาแชตส่วนตัว ตัวระบุ ภาพหน้าจอ หรือบันทึกการดำเนินการ
