# v3.0.1 — Perbaikan streaming local reader

[Semua bahasa](README.md) · [Unduh](https://github.com/bensonmaxai/line-desktop-mcp/releases/tag/v3.0.1) · [Instalasi](../quickstart-windows.md) · [Migrasi dan pemulihan](../MIGRATING.md#upgrading-to-v301)

![LINE Agent MCP](../assets/line-agent-cover-v3.png)

v3.0.1 adalah rilis patch untuk Issue #1. Rilis ini memperbaiki local reader yang menolak database hanya karena melampaui batas pembacaan seluruh berkas 256 MiB sebelumnya. Tidak ada tool MCP baru, perubahan perilaku UI, atau perluasan fitur keamanan; prasyarat dan batas operasional v3.0.0 tetap berlaku.

## Perubahan

- Input database terenkripsi kini dibaca dalam streamed chunks 1 MiB. Anggaran default adalah database 2 GiB, WAL 256 MiB, dan combined snapshot 2304 MiB. Ketiga batas tetap dapat dikonfigurasi dalam batas maksimum yang dibatasi.
- Pemeriksaan stabilitas database/WAL, pemeriksaan WAL yang sudah commit paling baru, dan validasi ulang session key sebelum reader membuka snapshot salinan tetap dipertahankan.
- Timeout default adalah 300 detik dan dapat dikonfigurasi. Setiap permintaan memakai direktori sementara tersendiri. Proses anak biasanya membersihkan file snapshot miliknya; pembersihan oleh proses induk hanya berjalan setelah proses anak dipastikan selesai. Jika penghentian belum terkonfirmasi, proses induk mempertahankan direktori hingga proses anak keluar.

## Verifikasi dan batasan

Kandidat rilis lulus 234 Node tests dan 124 dari 125 Python tests; satu skip adalah existing Windows file-symlink privilege test yang tidak tersedia untuk akun pengujian. Native crypto tests semuanya dijalankan. Pembacaan synthetic dengan database 853.438.464-byte plus WAL 4.152-byte, serta database 1.087.713.280-byte plus WAL yang sama, memverifikasi hasil commit terbaru, source hash tidak berubah, dan pembersihan temporary directory. Fixture tersebut mengamati process peak working set sekitar 39 MiB; ini bukan janji performa umum.

Reader tetap menyalin seluruh scoped source database sebelum query, bukan salinan berdasarkan page atau date saja. Build dan key discovery dimock pada validasi ini. Tidak ada pembacaan chat LINE nyata, alur pengiriman end-to-end, atau pengujian reporter machine.

## Upgrade

Gunakan GitHub tag `v3.0.1` atau lampiran `line-desktop-mcp-3.0.1.tgz` dan `SHA256SUMS.txt`; tidak ada rilis npm registry atau MCPB. Ekstrak ke sibling directory baru, jalankan `npm ci --ignore-scripts` di direktori package tersebut, arahkan launcher ke direktori baru, sambungkan kembali MCP client, lalu refresh schema. Tidak perlu menghapus atau memigrasikan LINE database. Simpan package dan launcher sebelumnya untuk rollback.
