# v3.1.0 — 本機唯讀 CLI

2026-09-22 · [GitHub Release](https://github.com/bensonmaxai/line-desktop-mcp/releases/tag/v3.1.0)

新增 `line-cli`，可查能力與本機狀態，並依指定聊天室及日期讀取、匯出 JSON／TXT／CSV。每次只處理一頁，日期最多 31 天；不操作 GUI，也不發送訊息。

本版保留既有 MCP 工具與 v3 安全界線。匯出不覆寫檔案，並核對寫入內容與雜湊；TXT／CSV 會列出省略欄位。

發布前安全檢查已修正 CLI 終端控制字元問題：人類可讀輸出改成可見跳脫文字，JSON 保留原始內容。

```powershell
node src/cli.js --version
node src/cli.js capabilities --json
node src/cli.js messages read --chat "Exact chat name" --from 2026-09-01 --to 2026-09-07 --limit 100 --json
```

驗證採合成資料與檔案系統回歸測試；本版未宣稱完成真實 LINE 聊天讀取、GUI 操作或發送測試。
