# v3.0.1 — Streamed local-reader repair

[All languages](README.md) · [Download](https://github.com/bensonmaxai/line-desktop-mcp/releases/tag/v3.0.1) · [Install](../quickstart-windows.md) · [Migration and rollback](../MIGRATING.md#upgrading-to-v301)

![LINE Agent MCP](../assets/line-agent-cover-v3.png)

v3.0.1 fixes Issue #1: the local reader no longer rejects a database solely for exceeding the former 256 MiB whole-file read limit. It adds no MCP tools, UI behavior, or security-feature expansion; v3.0.0 prerequisites and operating limits still apply.

## What changed

- Encrypted database input is read in 1 MiB streamed chunks. Defaults are 2 GiB for the database, 256 MiB for the WAL, and 2304 MiB for their combined snapshot; all three limits have bounded configuration caps.
- Database/WAL stability checks, latest-committed-WAL checks, and session-key revalidation remain before the copied snapshot opens.
- The reader timeout defaults to 300 seconds and is configurable. Each request owns one temporary directory. The child normally cleans its own snapshot files; parent cleanup runs only after confirmed child exit. If termination is unconfirmed, the parent retains the directory until exit.

## Verification and limits

The candidate passed 234 Node tests and 124 of 125 Python tests. The one skip is an existing Windows file-symlink privilege test unavailable to the test account; native crypto tests all ran. Synthetic reads of a 853,438,464-byte database plus a 4,152-byte WAL, and a 1,087,713,280-byte database plus the same WAL, verified the newest committed result, unchanged source hashes, and temporary-directory cleanup. Their peak process working sets were about 39 MiB, not a general performance promise.

The reader still copies the complete scoped source database before querying; it does not make a page- or date-only copy. Build and key discovery were mocked for this validation. No real LINE chat read, send end-to-end flow, or reporter-machine test was performed.

## Upgrade

Use GitHub tag `v3.0.1` or the attached `line-desktop-mcp-3.0.1.tgz` and `SHA256SUMS.txt`; there is no npm-registry or MCPB release. Extract into a new sibling directory, run `npm ci --ignore-scripts` in that package directory, point the launcher at the new directory, reconnect the MCP client, and refresh its schema. No LINE database deletion or migration is required. Keep the prior package and launcher for rollback.
