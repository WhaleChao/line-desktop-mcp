# v3.3.8 — 聊天室選取、草稿核對與獨立視窗引用修正

新增確切名稱候選查詢，區分既有聊天與尚未開聊的聯絡人，只回傳不透明的聊天室／帳號參照。唯一既有直聊可帶配對參照開啟；多個既有同名聊天仍拒絕猜選。視窗標題不是 DB 身分或傳送證據，同名綁定傳送仍需獨立畫面上下文核對。

草稿寫入共用同一次新快照完成完整值及 expectedDraft 核對，移除重複快照。相同草稿不輸入；改寫仍有完整讀回及聊天室變更拒絕。選用的開發計量預設關閉，只含固定計數與耗時，不記錄聊天內容或身分；不宣稱固定加速百分比。

修正引用來源確認誤要求主視窗的問題，改核對先前選取的確切獨立聊天視窗。HWND 更換、標題改變、最小化及來源像素改變仍會拒絕操作。收回指引補上背景點擊無效後的前景路徑，以及核對後改用內建 Computer Use 的方式。

實測涵蓋直聊／群組文字與 TXT 傳送後收回、多行／emoji 草稿寫入讀回清除、相同草稿不重複輸入、衝突原稿保留、錯誤聊天室／帳號拒絕、修補後引用來源確認、引導式引用草稿清理及原件轉傳收件人預覽取消。[驗證範圍與限制](../VALIDATION_v3.3.8.md)。

自繪「回覆」選單仍需看畫面選取。原件轉傳自動準備無法核對完整來源 OCR 時，會安全拒絕；引導式收件人預覽已通過並取消，沒有按分享。追加封測沒有送出引用回覆或轉傳，不把這些結果宣稱為全自動成功。

套件與 shrinkwrap 根版本已對齊，依賴不變。本版沒有新增個人 LINE 原生 API、接通原生 MCP、排程、全域設定或背景服務。
