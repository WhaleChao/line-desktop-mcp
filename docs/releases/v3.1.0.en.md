# v3.1.0 — Read-only local CLI

2026-09-22 · [GitHub Release](https://github.com/bensonmaxai/line-desktop-mcp/releases/tag/v3.1.0)

Add `line-cli` for capabilities, local status, and scoped chat reads and JSON/TXT/CSV exports. Each invocation returns one page over at most 31 days. It does not operate the GUI or send messages.

Existing MCP tools and v3 security boundaries remain. Exports never overwrite an existing file and verify the written content and hash; TXT/CSV identify omitted fields.

Pre-release security review fixed terminal-control injection in CLI human-readable output. Controls are rendered as visible escapes; JSON preserves original strings.

```powershell
node src/cli.js --version
node src/cli.js capabilities --json
node src/cli.js messages read --chat "Exact chat name" --from 2026-09-01 --to 2026-09-07 --limit 100 --json
```

Verification uses synthetic data and filesystem regression tests. No live LINE chat read, GUI action, or message send is claimed for this release.
