# v3.3.1 — グループ検索の修正

グループ検索結果が「チャット」と表示され、長い名前が省略される場合の `LINE_SEARCH_NOT_UNIQUE` 誤判定を修正しました。

- 単一の構造上の候補は画面移動のみに使用します。入力前に個別ウィンドウの完全一致タイトル、チャット、本人アカウント、グループ種別、名前の一意性を再確認します。送信直前の確認も維持します。
- 本人アカウントを照合済みの身元照会が `ownSenderRef` を返すよう修正しました。別アカウントは拒否します。
- 個人チャット、ツール仕様、依存関係、自動再送防止は変更しません。

Node 353 件合格。Python 136 件中 128 件合格、環境によるスキップ 8 件。実機では約 10.266 秒でグループの検索・表示・身元・空の入力欄を確認しました。この確認ではメッセージを入力・送信していません。実行コードは導入済みの `3.3.1-local.1` と同一です。今回の差分の安全性確認で確定した脆弱性はありません。リポジトリ全体の安全を保証するものではありません。

タイトルとローカル記録は独立した証拠であり、ウィンドウと DB の直接識別ではありません。Qt のアクセシビリティ情報は部分的な場合があります。複数候補では従来の完全名確認を維持し、身元が不明なら停止します。私的な会話・画像・診断記録は公開パッケージに含めません。
