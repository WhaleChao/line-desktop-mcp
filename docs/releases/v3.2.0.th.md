# v3.2.0 — เวิร์กโฟลว์ LINE ที่กำหนดขอบเขต

2026-09-23 · [CLI](../CLI.md) · [อัปเกรดและย้อนกลับ](../MIGRATING.md#upgrading-to-v320)

การส่งข้อความธรรมดาผ่าน Windows MCP ผูกกับแชตและตัวตนผู้ส่งที่ระบุอย่างตรงกัน แล้วตรวจข้อความใหม่ของตนใน DB/WAL ภายในเครื่อง กำหนดเวลา 30 วินาที โดยใช้ได้ 25 วินาทีสำหรับการป้อนข้อมูล และกันไว้ 5 วินาทีเพื่อตรวจบันทึก `RECORDED_LOCAL` หมายถึงพบข้อมูลในเครื่องเท่านั้น ไม่ได้พิสูจน์ว่าผู้รับได้รับหรืออ่านข้อความแล้ว หากผลไม่แน่นอน ให้ใช้ `idempotencyKey` เดิมเพื่อตรวจบันทึกแบบอ่านอย่างเดียว ไม่มีการส่งซ้ำอัตโนมัติ การตั้งใจส่งซ้ำต้องใช้คีย์ใหม่

คำสั่ง MCP อ่าน ค้นหา ส่งออก และตรวจสอบที่ระบุวันเดียวหรือ `dateFrom`/`dateTo` ครบถ้วนไม่เกิน 31 วัน ใช้ตัวอ่านข้อมูลในเครื่องที่จำกัดขอบเขตร่วมกัน คำสั่งเดิมที่ไม่ระบุวันที่ยังอ่านประวัติที่โหลดอยู่ใน UI ของ LINE `compareWithUi: true` เป็นการเปรียบเทียบ UI แยกต่างหาก และอาจทำให้แชตถูกทำเครื่องหมายว่าอ่านแล้ว

หน้าต่างแชตแยกและตัวเลือกไฟล์ตรวจ HWND, PID และชื่อหน้าต่าง `send_file_manual` เพียงเตรียมไฟล์ในตัวเลือกไฟล์ การกด Open หลังได้รับอนุมัติจึงเป็นการส่ง ส่วนขยาย Windows แสดง 26 tools ที่ใช้งาน และ alias เดิม 5 ตัวซ่อนจากรายการแต่ยังเรียกได้ รวม descriptor ที่พัฒนาแล้ว 31 ตัว `line-cli` แบบอ่านอย่างเดียวยังคงใช้คำสั่ง JSON/TXT/CSV เดิม

การตรวจ UI แบบมีผู้กำกับครอบคลุมข้อความแชตส่วนตัว/กลุ่มและบันทึกในเครื่อง เมนชันสีน้ำเงินจริง การตอบโดยอ้างอิง ส่งต่อ เรียกคืน ไฟล์ TXT/PNG สังเคราะห์และการอ่านสื่อ โพล โน้ต อัลบั้ม รีแอ็กชัน การสลับการแจ้งเตือน/หน้าต่าง การเปิดแผงสติกเกอร์ และการเปิดแล้วปิดแผงจับภาพ สิ่งเหล่านี้ไม่ใช่ผลทดสอบการทำงาน MCP แบบอัตโนมัติ การคัดลอกแบบตรงตัวและการแปลเป็นอังกฤษผ่าน UI แบบมีผู้กำกับผ่านการตรวจแล้ว แต่การเลือกข้อความที่วาดเองโดย MCP โดยตรงอาจยังถูกปฏิเสธ การนำทาง Files, Media และ Links ผ่าน UI แบบมีผู้กำกับผ่านการตรวจแล้ว แต่เครื่องมือ MCP สำหรับ Files เปิดได้เพียงเมนู More จากนั้นหา Files ไม่พบและคืน `LINE_FEATURE_UNAVAILABLE` โดยไม่เปิดแผง Files การปักหมุดรายการแชตทดสอบปิด→เปิด→ปิดและคืนสภาพเดิมแล้ว ไฟล์ TXT ที่ดาวน์โหลดมี SHA-256 ตรงกับต้นฉบับทุกประการ `get_line_draft` อ่านช่องร่างว่างในแชตส่วนตัวและกลุ่มหลังเปิดผ่าน Search ได้จริง ใช้เวลาประมาณ 2.3 วินาทีในการตรวจครั้งนั้น
