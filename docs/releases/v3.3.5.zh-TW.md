# v3.3.5 — 混合搜尋分類與標題 OCR 修正

2026-09-29（Asia/Taipei）

搜尋結果同時有一筆聊天室與另外的訊息命中時，30px 標題裁切底部留白不足，可能讀不完整名稱；細分類標頭貼邊 OCR 則可能漏字或漏筆數，讓唯一聊天室仍被拒絕。本版依各分類自己的 UIA 資料列裁切、將標題範圍調整為 35px，必要時給 OCR 加 16px 白邊；裁切座標映回原截圖，越界證據會拒絕。

仍須核對已選取頁籤、精確查詢、聊天室筆數、完整名稱、獨立視窗完整標題，以及本機帳號／聊天室身分。傳送防護不變。本修正只改善導覽證據，沒有新增顏色身分驗證，也不代表可逕行傳送訊息。

61 項相關測試全部通過、0 失敗：54 項範圍 OCR、精確搜尋、最佳化傳送及收件目標測試，加上 7 項原生 OCR 測試。三個已授權個人聊天室共五次真正主視窗冷搜尋抵達 READY，每次獨立視窗標題完全一致、本機身分吻合且輸入框空白。沒有輸入或發送訊息；獨立限縮審查未發現阻擋問題。

依賴、公開 schema、草稿處理與防重送紀錄不變。透過 GitHub 原始碼 tag、附檔 `.tgz` 與 `SHA256SUMS.txt` 發布；沒有 npm registry 或 MCPB。
