# v3.1.0 — ローカル読み取り専用 CLI

2026-09-22 · [GitHub Release](https://github.com/bensonmaxai/line-desktop-mcp/releases/tag/v3.1.0)

`line-cli` を追加しました。機能一覧、ローカル状態、指定チャットと日付の読み取り、および JSON／TXT／CSV 出力に対応します。1 回につき 1 ページ、期間は最大 31 日です。GUI 操作やメッセージ送信は行いません。

既存 MCP ツールと v3 の安全要件は維持されます。既存ファイルは上書きせず、書き込み内容とハッシュを確認します。TXT／CSV では省略した項目を示します。

公開前の安全確認で CLI の端末制御文字処理を修正しました。読みやすい出力では制御文字を可視のエスケープ表記にし、JSON は元の文字列を保持します。

```powershell
node src/cli.js --version
node src/cli.js capabilities --json
node src/cli.js messages read --chat "Exact chat name" --from 2026-09-01 --to 2026-09-07 --limit 100 --json
```

合成データとファイルシステムの回帰テストで検証しています。本リリースでは実際の LINE チャット読み取り、GUI 操作、送信の検証完了は主張しません。
