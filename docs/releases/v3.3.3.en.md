# v3.3.3 — Recent group picker correction

2026-09-29 (Asia/Taipei)

LINE's `_chat` table is a generic chat index and can contain group rows (`_midType=2`). The recent-chat picker previously treated every matching row as a direct-chat identity, so a valid group with both `_groupChat` and `_chat` records was excluded as a false conflict. It now considers only `_midType=0` rows as direct identities, matching the existing named-chat resolvers. Real cross-kind and conflicting-name exclusions remain.

Five focused Python recent-chat tests and three Node contract tests passed; two regression cases failed before the fix. In a target-only read of one authorized live group, the old path excluded it and the corrected path returned the same group reference. This was a metadata-only check: no chat text, GUI action or send. A narrow independent review found no blocking security issue. No full Node or Python suite is claimed for this patch.

There are no send, window or search-guard, tool-schema, dependency or journal changes. The release uses a GitHub source tag, attached `.tgz` and `SHA256SUMS.txt`; no npm-registry or MCPB publication.
