# v3.3.3 — Perbaikan daftar grup terbaru

2026-09-29 (Asia/Taipei)

Tabel `_chat` LINE adalah indeks chat umum dan dapat memuat baris grup (`_midType=2`). Sebelumnya daftar chat terbaru menganggap setiap baris tersebut sebagai identitas chat langsung, sehingga grup valid yang ada di `_groupChat` dan `_chat` keliru dikeluarkan sebagai konflik. Kini hanya `_midType=0` dianggap identitas langsung, sesuai resolver chat bernama yang sudah ada. Konflik jenis atau nama yang nyata tetap dikecualikan.

Lima tes Python terfokus untuk chat terbaru dan tiga tes kontrak Node lulus; dua kasus regresi gagal sebelum perbaikan. Pembacaan khusus satu grup yang diizinkan menunjukkan jalur lama mengecualikannya, sedangkan jalur baru mengembalikan referensi grup yang sama. Pemeriksaan ini hanya membaca metadata: tanpa isi pesan, GUI, atau pengiriman. Tinjauan independen yang terbatas tidak menemukan masalah keamanan yang menghalangi rilis. Tidak ada klaim bahwa seluruh tes Node atau Python dijalankan ulang.

Tidak ada perubahan pada pengiriman, pengamanan jendela atau pencarian, schema alat, dependencies, atau jurnal. Distribusi melalui tag sumber GitHub, lampiran `.tgz` dan `SHA256SUMS.txt`; tanpa npm registry atau MCPB.
