# LINE Desktop MCP 3.3.6

LINE Desktop 26.5 is recognized by its exact executable build. An unreadable small date or message no longer requires repeated OCR or right-click attempts.

`prepare_line_send_target` can return `PENDING_VISUAL_CONTEXT` with a context image and a token that expires after 90 seconds. Personally inspect the nearest date boundary and both newest messages, then call `confirm_line_send_context` with the displayed date, full texts, individual times and directions. Never infer hidden labels or use local database text as a visual observation. A hidden clock, clipped date or changed frame requires a new preparation.

Confirmation checks fresh account/chat references, the whole authorized local page, the exact window and context pixels, and an empty composer. `send_message_auto` consumes the accepted context before input and rechecks the original guards. READY does not approve a send; the user must already have approved the exact outgoing text. Existing idempotency and local receipt verification remain in place. A local receipt is not independent server delivery/read proof.

Optional `dateFrom`, `dateTo` and `messageLimit` narrow preparation to the caller-authorized scope within the newest three Taipei dates (at most 30 metadata-only records). Confirmation and subsequent sending preserve that narrower scope. No media decoding, new dependency, global configuration or background service is added.

Validation used a named, authorized direct chat: pending context → caller-observed READY → read-only context consumption, with eight scoped records and an empty composer. No draft or message was entered. Focused negative fixtures cover reused/expired tokens, incorrect observations, account/chat changes, message/page and pixel changes, window movement, and nonempty drafts.

The observed CUA 0.28.2 legacy right-click alias is routed through its advertised `click(button:right)` interface, preserving exact window/coordinates and delivery mode. Other versions keep native semantics; the affected build refuses right-click when its safe interface is missing.
