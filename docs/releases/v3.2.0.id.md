# v3.2.0 — Alur kerja LINE dengan cakupan terbatas

2026-09-23 · [CLI](../CLI.md) · [Upgrade dan rollback](../MIGRATING.md#upgrading-to-v320)

Pengiriman teks biasa melalui Windows MCP kini mengikat identitas chat dan pengirim sendiri secara tepat, lalu memeriksa pesan baru milik sendiri di DB/WAL lokal. Batas 30 detik menyediakan 25 detik untuk input dan lima detik untuk pemeriksaan catatan. `RECORDED_LOCAL` hanya berarti catatan lokal ditemukan, bukan bukti pesan diterima atau dibaca penerima. Gunakan `idempotencyKey` yang sama untuk memeriksa operasi yang belum pasti; pemeriksaan ulang hanya membaca catatan dan tidak mengirim ulang. Pengiriman ulang yang disengaja memerlukan kunci baru.

Pembacaan, pencarian, ekspor, dan verifikasi MCP dengan satu tanggal atau pasangan `dateFrom`/`dateTo` lengkap maksimal 31 hari menggunakan pembaca lokal bersama yang dibatasi cakupannya. Permintaan lama tanpa tanggal tetap membaca riwayat yang sudah dimuat di UI LINE. `compareWithUi: true` menjalankan perbandingan UI terpisah dan dapat menandai chat sebagai telah dibaca.

Jendela chat terpisah dan pemilih file diverifikasi lewat HWND, PID, dan judul. `send_file_manual` hanya menyiapkan lampiran di pemilih file; tindakan Open setelah persetujuan mengirimnya. Ekstensi Windows menampilkan 26 tools aktif. Lima alias lama tetap dapat dipanggil tetapi disembunyikan, sehingga ada 31 descriptor yang diimplementasikan. `line-cli` baca-saja dengan perintah JSON/TXT/CSV tetap tersedia.

Pemeriksaan UI terpandu mencakup pengiriman langsung/grup dan catatan lokal, mention biru yang nyata, balasan kutipan, penerusan, penarikan, lampiran TXT/PNG sintetis dan pembacaan media, polling, catatan, album, reaksi, pengaturan notifikasi/jendela, membuka panel stiker, serta membuka lalu membatalkan panel tangkapan. Ini bukan bukti eksekusi tool MCP secara otonom. Penyalinan teks persis dan terjemahan bahasa Inggris melalui UI terpandu lulus pemeriksaan, tetapi penargetan langsung oleh MCP pada teks yang digambar khusus masih dapat ditolak. Navigasi Files, Media, dan Links melalui UI terpandu lulus. Entri fitur Files pada MCP hanya membuka menu More, gagal menemukan Files, lalu mengembalikan `LINE_FEATURE_UNAVAILABLE`; panel Files tidak terbuka. Sematan daftar chat diuji mati→aktif→mati dan dikembalikan ke keadaan awal. File TXT yang diunduh memiliki SHA-256 yang persis sama dengan sumber. `get_line_draft` membaca composer kosong pada chat langsung dan grup setelah dibuka lewat Search dalam sekitar 2,3 detik pada pemeriksaan tersebut.

Rilis tersedia melalui tag sumber GitHub dan lampiran `line-desktop-mcp-3.2.0.tgz`; tidak ada publikasi npm registry atau MCPB.
