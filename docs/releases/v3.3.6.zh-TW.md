# LINE Desktop MCP 3.3.6 更新說明

已支援 LINE Desktop 26.5.0.3975 的確切版本核對。小字日期或訊息漏讀時，準備核對會提供畫面與短效 token，讓呼叫端直接看圖確認。

`prepare_line_send_target` 回傳 `PENDING_VISUAL_CONTEXT` 時，請親自讀取圖片中的最近日期分界、最後兩則完整原文、各自時間與方向，再以 `confirm_line_send_context` 提交觀察。token 有效 90 秒，只能確認一次；日期或時間看不清楚時，重新準備。不要把資料庫原文直接當成看圖結果。

確認會重讀原核准範圍，核對帳號／聊天室識別、完整訊息頁、同一視窗與畫面指紋，並確認輸入框空白。正式送出前消耗這份確認，沿用較窄的讀取範圍；原有傳訊授權、防重送及本機訊息覆核仍保留。`READY` 只表示可開始，傳送文字仍須已有使用者批准。

可用 `dateFrom`、`dateTo`、`messageLimit` 限縮準備核對；日期限最近三個台北日期，最多 30 筆，僅讀文字與附件中繼資料。未增加媒體解碼、套件依賴、全域設定或背景服務。Windows CUA 0.28.2 的右鍵別名改用其正式 `click(button:right)` 介面，保留指定視窗、座標與投遞模式。

本次實測完成「待畫面確認 → READY → 唯讀消耗送出前 guard」，維持核准的八筆紀錄與空白輸入框；沒有輸入或發送任何訊息。測試也涵蓋 token 重用／過期、觀察不符、帳號／聊天室或訊息頁變動、畫面變動及非空草稿拒絕，獨立限定安全審查沒有剩餘阻擋問題。本機覆核不代表獨立的伺服器送達或已讀證明。
