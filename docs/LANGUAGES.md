# Documentation languages

[繁體中文](../README.md) · [English](README.en.md) · [日本語](README.ja.md) · [ภาษาไทย](README.th.md) · [Bahasa Indonesia](README.id.md)

The v3.0.1 overview and release notes are available in five languages. The technical tool contract and installation guide are maintained in English; exact API identifiers and configuration names are identical in every language.

| Documentation | Intended readers |
| --- | --- |
| Traditional Chinese (`zh-TW`) | Taiwan and Traditional Chinese readers |
| Japanese (`ja`) | Japan and Japanese readers |
| Thai (`th`) | Thailand and Thai readers |
| Indonesian (`id`) | Indonesia and Indonesian readers |
| English (`en`) | Shared international edition |

This is a practical first set, not an exhaustive list of countries with LINE users. LY Corporation's [international business overview](https://www.lycorp.co.jp/en/company/global/) highlights Japan, Taiwan and Thailand. LINE's [July 15, 2026 cross-market usage article](https://www.linecorp.com/ko/pr/news/global/20260715) explicitly covers Japan, Taiwan, Thailand and Indonesia. Sources checked September 11, 2026; country presence is not a claim of equal popularity.

Translated documentation does **not** certify the corresponding LINE UI language. Live Windows GUI evidence currently covers LINE 26.4.2.3957 in Traditional Chinese. Date filtering and poll planning currently use `Asia/Taipei` (`UTC+08:00`) in every documentation locale. Missing or ambiguous UI controls are refused.

Corrections are welcome through issues or pull requests. Keep scope, version, media limits, approval boundaries and migration notes consistent across translations.
